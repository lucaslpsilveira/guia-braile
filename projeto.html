Sobre o Projeto

O que é?

Desenvolvido pelos alunos José Felipe Rodrigues Serpa, Lucas Pedreira da Silveira e Pietro de Almeida Lopes no Instituto Federal Sul-rio-grandense Campus Charqueadas, O guia Braille é um ambiente que possibilita que você aprenda o Braille de forma fácil, interativa e estimulante. Esta ferramenta é voltada principalmente para deficientes visuais, porém pode ser usada por toda e qualquer pessoa que tenha interesse pelo assunto.

Como funciona?

As informações presentes no site serão transmitidas através de áudios e textos, possibilitando que você possa usar o método que mais lhe convém. Para o estudo do Braille, em primeiro momento, o site irá lhe apresentar os principais conceitos da simbologia. Em um segundo momento, você será levado a desempenhar atividades interativas, que são jogos de ensino de Braille.

Como faço para navegar pelo site sem o auxílio do mouse?

Para navegar pelo site sem o auxílio do mouse é muito simples! Basta pressionar a tecla “tab” de seu teclado para alterar entre os elementos. A cada elemento selecionado, um áudio será emitido para lhe auxiliar. Pressione “tab” e experimente agora mesmo!

Para usar o sistema é preciso utilizar um teclado adaptado para o Braille

Os jogos interativos necessitam de um teclado adaptado para o Braille. Porém, você não precisa gastar muito em um teclado adaptado, pois o Guia Braille ensina como fazer seu próprio teclado, basta acessar o campo “Faça seu Teclado” no menu superior ou clicar no link abaixo.
